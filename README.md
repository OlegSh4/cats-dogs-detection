# Проект по обнаружению объектов

## Описание
Этот проект посвящен разработке и обучению модели для задачи обнаружения объектов на изображениях. В проекте используется архитектура на основе ResNet50 и Faster R-CNN для предсказания классов объектов и их координат bounding box. Основное внимание уделяется детекции кошек и собак на изображениях.

## Данные
Данные для проекта содержатся в архиве `animals.zip`, который включает изображения кошек и собак с соответствующими XML-аннотациями. Архив должен быть распакован в рабочую директорию.

## Предобработка данных
- **Распаковка архива**: Изображения и аннотации извлекаются из архива.
- **Парсинг XML**: Функция `parse_xml` извлекает координаты bounding box и метки объектов из XML-файлов.
- **Создание датасета**: Класс `AnimalDetectionDataset` используется для загрузки и преобразования данных.

## Модели
В проекте используются две модели:
1. **Кастомная двухголовая сеть на основе ResNet50**: Одна голова предсказывает класс объекта, другая — координаты bounding box.
2. **Faster R-CNN с backbone ResNet50**: Используется для сравнения производительности.

## Обучение модели
Модели обучаются на предобработанных данных с использованием комбинированной функции потерь (MSELoss для регрессии и CrossEntropyLoss для классификации). В процессе обучения выводятся значения функции потерь для отслеживания прогресса.

## Результаты
Модели оцениваются на основе метрик точности классификации и IoU для bounding box. Результаты обучения и тестирования сохраняются и визуализируются.

## Визуализация
Для визуализации результатов используется функция `show_image_with_bounding_box`, которая отображает изображения с наложенными bounding box для истинных и предсказанных объектов.
